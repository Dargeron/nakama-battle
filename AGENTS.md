# Ninja Chakras / Ultimate Nakama Ninja Battle

This repository is the browser remake of Albert Casals's 2016 game. The complete
client, original assets, and authoritative online server are included.

## Commands

- Install: `npm ci` (Node.js 22 or newer; Python 3 for deployment/local serving).
- Tests: `npm test` (110 regression tests; DOM harness is not browser rendering).
- Build offline download: `npm run build`.
- Static preview: `npm start`, then open http://localhost:8000.
- Online development: `npx wrangler@4 dev` with the included wrangler.jsonc.
- Existing production: https://ultimate-nakama-battle.bauldejuegos.workers.dev/
- Cloudflare deployment details: docs/DEPLOYMENT.md.

## Architecture and important invariants

- `dist/` is the canonical client source, despite its name. Do not delete it as
  generated output. Only `dist/nakama-offline.html` is generated by the build.
- `dist/game-data.js` preserves recovered Unity data. Owner-requested exceptions
  belong in `dist/catalog.js`, including Voluntad's zero opening cooldown.
- The same `dist/engine.js` runs locally and on the server. It has module-global
  state. Server room operations must restore their snapshot and finish the
  engine mutation synchronously before awaiting storage or other I/O.
- Online clients send commands, never invented damage or outcomes. Room
  revisions reject duplicates/stale moves; reconnect restores server state.
- Both friends keep their own team below. Mirror characters across teams are
  allowed; duplicates inside one team are not.
- Attacks execute immediately after selecting a target. Single click selects,
  double click/tap inspects. No queue or undo. Flexible chakra allocation stays
  adjustable before execution; keep the target tray below the lower team.
- Chakra F/Strength is green; R/Rationality blue; P red; E white; C/any black.
- Keep original ability artwork/descriptions/music. No sudden death. Auto-pass
  is optional and off initially. Continue appears only for unfinished games.
- Stun consumes scheduled outward periodic ticks without damage or catch-up.
  Protection, self effects, and delayed self costs continue while stunned.
- Voluntad has zero opening cooldown and its original six-turn reuse cooldown.
  Locura retains its five-turn opening cooldown. Borracha never resets it.

After client changes, run appropriate tests and regenerate the offline HTML.
Do not commit tokens, browser data, node_modules, or local Cloudflare state.
Preserve the existing production Worker name and Durable Object namespace.
Only deploy when requested. Do not claim visual/audio QA from the DOM tests.
